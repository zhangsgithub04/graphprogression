How this works

For every unordered pair (u,v), toggle adjacency if degree(u) = degree(v); otherwise retain adjacency. All decisions use degrees from the current state simultaneously. The map contains 2n(n−1)/2 labeled states. Each has exactly one successor. Every component ends in a cycle. Layers use the exact number of steps until a cycle; cycle periods are measured, never assumed. Enumeration is limited to n ≤ 6 (32,768 states); n = 7 would require 2,097,152 states. Computation runs in a background worker; canvas renders the map without creating thousands of page elements.
